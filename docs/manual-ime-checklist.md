# 輸入法手動測試清單

自動化測試無法模擬真實的中文輸入法（注音、拼音、倉頡等），所以每次發佈前請由真人在實機上跑一遍這份清單。不需要會寫程式。

## 事前準備

1. 開啟應用程式，建立一篇新筆記，標題先留空。
2. 在下表的欄位標題確認你使用的環境：**Windows Chrome**、**macOS Chrome**、**macOS Safari**。每個環境至少用一種輸入法（建議：注音；Windows 也可用「微軟新注音」）。
3. 在「結果」欄打勾（✅）代表正常；打叉（❌）代表有問題，並照最後一節的方式回報。**沒測的欄位留空**。
4. 每個情境都要確認三件事：
   - **字有沒有進來**：打的字、順序、選的字都正確，沒有重複、缺字或跑到別的位置。
   - **游標位置**：打完後游標停在剛輸入文字的後面。
   - **組字框**（輸入法下方帶底線的字）：完成後底線消失，沒有殘留。

## A. 輸入法測試台的 12 個情境

| # | 情境 | 怎麼做 | 預期結果 | Windows Chrome | macOS Chrome | macOS Safari |
|---|---|---|---|:-:|:-:|:-:|
| 1 | 空白段落開頭打字 | 在空白段落用注音打「你好嗎」，選字後按空白鍵確認 | 文字「你好嗎」出現在段落，沒有多餘空白 | ✅ | ☐ | ☐ |
| 2 | 段落中間插入 | 先輸入「前面後面」，把游標移到兩者中間，再用注音打「中間」 | 變成「前面中間後面」，後面的字沒有被吃掉 | ✅ | ☐ | ☐ |
| 3 | 粗體文字裡打字 | 輸入一段文字並選取後按 Ctrl/⌘+B 變粗體，游標放在粗體字中間，用注音插入「測試」 | 插入的字也是粗體，原本的粗體不消失 | ✅ | ☐ | ☐ |
| 4 | 選字後按 Enter | 用注音打「你好」，在選字窗出現時直接按 Enter（不按空白） | 組字內容被確認，**不會**同時換行；再按一次 Enter 才換行 | ✅ | ☐ | ☐ |
| 5 | **待辦清單裡打字（已知問題，必測）** | 用 `/待辦清單` 建立待辦，在項目裡輸入數字 `1234567890`，再用注音打一句中文 | 數字依序顯示為 `1234567890`，**不可顛倒**（已知問題：數字順序可能顛倒）；中文正常 | ✅ | ☐ | ☐ |
| 6 | 標題裡打字 | 在文件內用 `/標題 1` 建立標題，用注音打「年度計畫」 | 標題文字正確，組字中不會跳出選單或換行 | ✅ | ☐ | ☐ |
| 7 | 組字中刪除 | 用注音打「ㄋㄧ」（尚未選字），按 Backspace 刪掉組字中的符號，再重新打完整個字 | 只刪掉組字中的符號，**已確認的文字不受影響**；最後得到正確的字 | ✅ | ☐ | ☐ |
| 8 | 選取文字後直接輸入 | 輸入「舊文字」並用滑鼠選取，直接用注音打「新文字」 | 舊文字被取代為「新文字」，沒有殘留 | ✅ | ☐ | ☐ |
| 9 | 跨段落選取後輸入 | 建立三個段落，從第一段中間選取到第三段中間，直接用注音打「合併」 | 選取範圍被取代，剩下的前後文字接在「合併」前後，沒有重複或遺失 | ✅ | ☐ | ☐ |
| 10 | 快速連續輸入長句 | 不停頓地用注音連續打約 50 字的長句 | 全部文字完整、順序正確，沒有掉字，畫面沒有明顯卡頓 | ✅ | ☐ | ☐ |
| 11 | 程式碼區塊裡打字 | 用 `/程式碼` 建立區塊，用注音打中文註解 `// 測試` | 文字正確，不會觸發自動換行或語法高亮錯亂 | ✅ | ☐ | ☐ |
| 12 | 復原組字結果 | 用注音打一句話並確認，按 Ctrl/⌘+Z | 整句被復原（或依輸入法行為以一次確認為單位復原），不會留下半個字；再按 Ctrl/⌘+Shift+Z 可重做 | ✅ | ☐ | ☐ |

| 17 | 快速切換搜尋框中組字 | 按 Ctrl/⌘+K 開啟快速切換，用注音打「採購」；組字中按 Enter 確認選字 | 組字中不會開啟或建立任何筆記；確認後搜尋結果才更新，結果與輸入文字相符 | ✅ | ☐ | ☐ |
| 18 | 側欄重新命名中組字 | 在側欄對筆記按右鍵 →「重新命名」，用注音打「新名稱」，組字中按 Enter 確認選字，再按一次 Enter | 第一次 Enter 只確認選字，名稱沒有被提早送出；第二次 Enter 才完成改名 | ✅ | ☐ | ☐ |

## 如何回報問題

請把問題記錄在 GitHub Issue（或直接傳給開發者），每個問題一則，內容包含：

1. **清單編號與名稱**（例如「#14 筆記連結建議 `[[` 中組字」）。
2. **環境**：作業系統與版本、瀏覽器與版本、輸入法（例如「macOS 15、Safari 18、注音」）。
3. **實際發生什麼事**：打了什麼、看到什麼（例如「打『採購』時第一個字重複出現」）。
4. **預期應該怎樣**：可直接複製表格的「預期結果」。
5. **能否重現**：每次都會 / 偶爾 / 只出現一次。
6. **截圖或螢幕錄影**（強烈建議；組字問題用文字很難描述）。

發現「已知問題」（#5 數字順序顛倒）時也請回報，並註明是否與上次相同，方便追蹤是否已修好。
